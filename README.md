# พอร์ตโฟลิโอ นางสาวอัจฉรา ทับทิมฉิม — คู่มือใช้งาน

เว็บไซต์พอร์ตโฟลิโอ 12 หน้า ธีมวิชาการ (กรมท่า+ทอง, ฟอนต์ Sarabun) แต่ละหน้าเป็นไฟล์ .html แยกกัน
โครงสร้างและฟีเจอร์เดียวกับพอร์ตก่อนหน้า (คลิกรูปเพื่อซูม, เมนูเต็มจอ, ทรานซิชันเปลี่ยนหน้าแบบเนียน, กรอบทองรอบรูป)

## โครงสร้างไฟล์
```
achara-portfolio/
├── index.html      ← 01 Portfolio (ปกหน้า)
├── page-02.html     ← 02 Profile ประวัติส่วนตัว
├── page-03.html     ← 03 Statement of Purpose
├── page-04.html     ← 04 Academic Record ผลการเรียน
├── page-05.html     ← 05 Activities — Engineering Camps
├── page-06.html     ← 06 Activities — Academic Workshops 1
├── page-07.html     ← 07 Activities — Academic Workshops 2
├── page-08.html     ← 08 Activities — Volunteer Activities
├── page-09.html     ← 09 Activities — Activities & Leadership
├── page-10.html     ← 10 Certificate
├── page-11.html     ← 11 Contact
├── page-12.html     ← 12 Thank You
├── style.css       ← ดีไซน์ทั้งหมด (ใช้ร่วมกันทุกหน้า)
├── app.js         ← เมนู, ปุ่มเลื่อนหน้า, กล้องซูมรูป (ใช้ร่วมกันทุกหน้า)
└── images/        ← ไฟล์รูป page-01.jpg ถึง page-12.jpg
```

## หมายเหตุสำคัญ
- **หน้า 11 (Contact) และหน้า 12 (Thank You) ยังเป็นรูปเปล่าๆ** (พื้นสีฟ้าอ่อน ยังไม่มีเนื้อหา) ตามที่บอกว่ายังไม่เสร็จ — พอออกแบบเสร็จแล้ว แค่เอารูปใหม่ไปแทนที่ไฟล์ `images/page-11.jpg` และ `images/page-12.jpg` ชื่อเดิมเป๊ะ ไม่ต้องแก้โค้ดใดๆ เว็บจะขึ้นรูปใหม่ทันที
- ทุกรูปมี**กรอบสีทอง**ล้อมรอบ ช่วยให้เห็นขอบเขตของหน้าชัดเจน โดยเฉพาะหน้าที่ยังเป็นพื้นว่างๆ
- ขนาดตัวอักษร (หัวข้อหน้า, เลขหน้า) ปรับให้ใหญ่อ่านง่ายขึ้นแล้ว

## ฟีเจอร์ในเว็บ
- คลิกที่รูปเพื่อขยายเต็มจอ พร้อมซูมเข้า/ออก ลากเลื่อนดู ดับเบิลคลิก/แตะซูมเร็ว
- เมนูเต็มจอ (ไอคอน ☰) แสดงหัวข้อทั้ง 12 หน้า พร้อมแอนิเมชันไล่จังหวะ
- ปุ่มก่อนหน้า/ถัดไป + ปัดซ้ายขวาบนมือถือ + ลูกศร ← → บนคีย์บอร์ด
- ทรานซิชันเปลี่ยนหน้าแบบ fade เนียนๆ (เบราว์เซอร์ที่รองรับ)
- แสงสีทองจางๆ ตามเคอร์เซอร์บนหน้าปก/ปกหลัง

## อัปโหลดขึ้น GitHub Pages (ฟรี)
1. สร้าง repository ใหม่ (Public) ที่ https://github.com
2. Add file → Upload files → ลากไฟล์ .html ทั้งหมด, `style.css`, `app.js`, โฟลเดอร์ `images` เข้าไปที่ root แล้ว Commit
3. Settings → Pages → Source: Deploy from a branch → branch main, โฟลเดอร์ / (root) → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
